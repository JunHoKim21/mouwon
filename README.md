# 🐾 고양이 온천 여관 : 묘유원(猫湯院)

> 눈 덮인 삼나무 숲속 노천탕에서 고양이가 되어 쉬어가는 **3D 프로시저럴 힐링 온천 웹 월드**

외부 3D 모델이나 오디오 파일 없이 **Three.js 프로시저럴 지오메트리·Canvas2D 절차적 텍스처·Web Audio API 합성 사운드**만으로 구현된 인터랙티브 웹 애플리케이션입니다.

---

## 📖 사용법

### 1. 로컬 실행 방법

```bash
# 1) 의존성 설치 (vite@8 / esbuild@0.25 peerOptional 충돌 방지를 위해 --legacy-peer-deps 권장)
npm install --legacy-peer-deps

# 2) 혼자 체험 (프론트엔드만 실행 -> http://localhost:3000 접속)
npm run dev

# 3) 실시간 멀티플레이어 체험 (터미널 2개에 각각 실행 -> http://localhost:3000 다중 탭 접속)
npm run server   # 터미널 1: WebSocket 룸 서버 (3001 포트)
npm run dev      # 터미널 2: Vite 개발 서버 (/ws -> 3001 프록시)
```

| 명령어 | 설명 |
| :--- | :--- |
| `npm run dev` | Vite 개발 서버 실행 (`http://localhost:3000/`) |
| `npm run server` | 개발용 Express + WebSocket 멀티플레이 룸 서버 실행 (`tsx server/index.ts`, `ws://localhost:3001/ws`, `/health`) |
| `npm run build` | 프론트엔드(`dist/`) + 서버(`dist-server/index.js`) 프로덕션 번들 빌드 |
| `npm run start` | 사전 빌드된 `dist-server/index.js` 실행 (`dist/` 정적 파일 + `/ws` 단일 포트 통합 서빙) |
| `npm run lint` | TypeScript 타입 체크 (`tsc --noEmit`) |
| `npx tsx --test server/*.test.ts src/world/*.test.ts` | 룸 매니저·원격 보간·길찾기·지형 충돌·NPC 대열·상호작용 단위 테스트 실행 |

> 필요 시 [.env.example](.env.example)을 참고해 환경 변수를 설정할 수 있습니다. (현재 3D 월드 체험에는 별도 API 키 없이 바로 동작합니다.)

### 2. 기본 조작 & 단축키

| 입력 | 동작 |
| :--- | :--- |
| **`W` `A` `S` `D` / `방향키`** | 카메라 시점 기준 자유 이동 |
| **바닥 · 다리 · 마루 클릭** | A\* 경로 탐색 기반 자동 도보 이동 (상단 배너 클릭 또는 `ESC`로 중단) |
| **마우스 드래그 / 휠** | 카메라 회전 및 줌 인/아웃 |
| **오브젝트 클릭 또는 `F`** | 근처 상호작용 오브젝트 실행 (하단 안내 버튼 클릭도 가능) |
| **`G`** | 🐾 코 인사 |
| **`B`** | 🍞 꾹꾹이 (누적 횟수 증가) → 식빵 굽기 자세 전환 |
| **`E`** | ♨️ 노천탕 입욕 (수건·머리 위 유자 연출) |
| **`T`** | 🐈 산책 동행 합류/해제 (최대 2마리 동행 · 혼잡 방지) |
| **`M` / 숫자 `1`~`5`** | 🎋 대나무 실로폰(C 메이저 5음계: 도·레·미·솔·라) 패널 토글 및 연주 |
| **`ESC`** | 자동 이동 멈추기 / 평상·휴식 자세에서 일어나기 |

### 3. 여관 스팟 & 주요 기능

1. **📍 장소 걸어가기 (우측 상단 드롭다운)**
   - **8개 주요 명소**(온천 입구 다리, 노천 편백탕, 고양이 난로방, 따뜻한 유자 연못, 우유 자판기 & 평상, 대나무 숲 물통, 아궁이 장작터, 족욕 개울)로 장애물과 계단을 우회해 걸어갑니다.
2. **🍊 감사·응원 유자 연못**
   - 연못을 클릭하거나 근처에서 `F`를 눌러 5가지 색상의 유자에 최대 40자 감사·응원 쪽지를 띄우고, 떠 있는 유자를 눌러 메시지를 읽을 수 있습니다.
3. **🥛 우유 자판기 & 원목 평상**
   - 평상에 앉아 쉬면 오목눈이(뱁새)가 날아와 곁에 앉습니다.
   - `B` 키 또는 버튼으로 **꾹꾹이 25회**를 채우면 자판기에서 따뜻한 음료 4종(바나나우유, 딸기우유, 흰우유, 녹차우유)을 뽑아 마시거나 주변 고양이에게 선물할 수 있습니다.
4. **🪵 아궁이 장작터 (2단계)**
   - ① 장작 더미에서 장작 1개비 집기(`F`/클릭) → ② 아궁이에 장작 넣기(`F`/클릭)로 불꽃과 온천 김이 강해집니다.
5. **🎋 대나무 숲 물통 & 🥚 온천 달걀**
   - 대나무 물통을 클릭해 맑은 대나무 물소리를 울리거나, 원천 바구니에 온천 달걀을 담가 반숙 체험을 할 수 있습니다.
6. **🧶 털실 굴리기 100 카운터 · 📸 추억 사진 저장 · 🎚️ 온천 소리 조절 · 🌙 낮/밤 전환**
   - 털실을 드래그/스크롤해 최대 100바퀴를 감아볼 수 있고, 입욕·평상 휴식 중에는 추억 사진 저장 버튼이 활성화됩니다. (모바일에서는 `navigator.share` 기반 공유를 지원하며, 카카오톡 인앱 브라우저 접속 시 외부 브라우저 전환 안내를 제공합니다.)
   - 우측 상단 메뉴에서 **환경음·골골송·효과음 볼륨/음소거** 조절과 **낮 설경 ↔ 밤 온천** 전환, 하단 도크에서 **고양이 털 무늬 6종**(치즈태비, 삼색이, 턱시도, 고등어태비, 깜장이, 크림냥) 변경이 가능합니다.
7. **👥 실시간 WebSocket 멀티플레이 룸 (`16명` 정원 자동 분산 · `?room=` 초대 · `혼자 보기`)**
   - 백엔드 서버 연결 시 방당 최대 `16명`까지 같은 온천 방에 배정되며(초과 시 `2번 방` 등으로 자동 분산), 다른 플레이어 고양이 이동·장작 넣기·대나무 물통·감사 유자 쪽지·우유 선물이 실시간 동기화됩니다.
   - 상단 **방 배지 클릭**으로 `?room=` 초대 링크를 복사해 지인과 같은 방에 합류할 수 있으며, **`혼자 보기`** 버튼으로 다른 플레이어 고양이와 유자 쪽지를 함께 가릴 수 있습니다(유자 쪽지 금칙어 필터링 적용). 서버 미연결 시에도 `오프라인` 모드로 모든 1인 기능을 그대로 이용할 수 있습니다.

## 🛠️ 사용 기술 (Tech Stack)

| 영역 | 기술 / 라이브러리 | 활용 내용 |
| :--- | :--- | :--- |
| **UI & 프레임워크** | React 19, TypeScript, Tailwind CSS v4 | HUD, 장소 이동 메뉴, 모달(유자 쪽지·자판기·털실·추억 사진), 반응형 레이아웃 |
| **3D 엔진 & 렌더링** | Three.js (`^0.187.0`), `RoomEnvironment`, `PCFShadowMap` | 프로시저럴 3D 고양이/주변 고양이 아바타, 눈 덮인 산·온천 건축물, 셰이더 물결, 낮/밤 라이팅·안개 전환, 눈·김 파티클 |
| **절차적 텍스처** | HTML5 Canvas2D (`CanvasTexture`) | 편백나무 목재·돌·실내 난로방·창호지·대나무·고양이 무늬·표지판/수건 텍스처 실시간 생성 |
| **경로 탐색 & 물리** | 커스텀 2D 그리드 A\* (`pathfinding.ts`), 충돌 해석 (`terrainMath.ts`) | 온천 턱·바위 링·난로방 벽면 우회 및 계단/툇마루 게이트 기반 자동 도보 경로 산출, 지형 높이 보간, 3인칭 댐핑 카메라 |
| **절차적 오디오** | Web Audio API (`onsenAudio.ts`) | 핑크 노이즈 온천 물소리·바람, 거리/행동 비례 공간 골골송, 5음계 대나무 실로폰·물통·발소리·효과음 합성 |
| **실시간 멀티플레이어** | Express, `ws` (WebSocket) | 방당 `16명` 정원 자동 분할, `100ms` 상태 스로틀링·보간, 공용 유자 쪽지/장작/대나무/우유 선물 동기화 |
| **아이콘 & 모션** | Lucide React, Motion | UI 아이콘 및 모달/컴포넌트 인터랙션 |
| **빌드 & 테스트** | Vite 8.3, `@vitejs/plugin-react`, `tsx`, Node `node:test` | 개발/번들 빌드 및 수학·길찾기·동행·상호작용 단위 테스트 |

## 🚀 다인 접속 확장 로드맵

1. **1단계 · 혼잡 방지 UX + 세계관 순화 (완료)**: 산책 동행 최대 2마리 제한, 한국어 용어 순화 및 정적 빌드 구축

## 🌐 Render 원서버 배포 가이드

Express가 빌드된 `dist/` 정적 파일과 `/ws` WebSocket 서버를 한 포트(`PORT`)에서 함께 서빙하므로 Render **Web Service** 1개로 바로 배포할 수 있습니다. ([render.yaml](render.yaml), [.npmrc](.npmrc) 포함)

* **Build Command**: `npm install --include=dev && npm run build`
* **Start Command**: `npm start`
* **Health Check Path**: `/health`
